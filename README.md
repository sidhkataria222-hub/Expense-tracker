# 💸 ExpenseFlow – Smart Expense Tracker

**Track Smart. Spend Wise. Save Better.**

ExpenseFlow is a modern, full-stack personal finance management platform built for college students and working professionals. It helps users track income and expenses, manage budgets, analyze spending habits, monitor savings goals, and make smarter financial decisions with AI-powered insights.

## 🚀 Features

- 📊 **Smart Dashboard** – Real-time overview of income, expenses, balance, and savings.
- 💰 **Expense Management** – Add, edit, delete, and categorize transactions.
- 📅 **Budget Planning** – Set monthly budgets and monitor spending limits.
- 🤖 **AI Financial Assistant** – Get personalized financial insights and saving suggestions.
- 📈 **Advanced Analytics** – Interactive charts to understand spending patterns.
- 🎯 **Savings Goals** – Create financial goals and track progress.
- 🔔 **Smart Notifications** – Get alerts for budget limits and upcoming payments.
- 🔄 **Recurring Transactions** – Manage subscriptions, bills, and regular payments.
- 🔐 **Secure Authentication** – Personalized accounts and protected financial data.
- 📱 **Responsive UI** – Seamless experience across desktop, tablet, and mobile.

## 🎯 Target Audience

- **College Students:** Manage pocket money, daily expenses, hostel fees, food, travel, and subscriptions.
- **Working Professionals:** Track monthly salaries, bills, investments, savings, and personal budgets.
